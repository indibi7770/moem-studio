Moeum Studio

모음스튜디오는 음악 플레이리스트 유튜브 채널을 운영하는 사람을 위한 PC용 작업 프로그램입니다. 곡 기획, 영상 만들기, 썸네일, 설명글·번역 작성, 유튜브 업로드까지 한 화면에서 처리합니다. 프로그램과 작업 파일은 모두 사용자의 PC에 저장됩니다.

Google 계정 연결

사용자가 직접 Google 계정을 연결하면, 모음스튜디오는 YouTube Data API를 사용해 완성된 영상을 사용자 본인의 유튜브 채널에 올리고 제목·설명·태그를 설정합니다. 연결은 언제든지 Google 계정 권한 페이지에서 해제할 수 있습니다.

About (English)

Moeum Studio is a desktop application for people who run music playlist channels on YouTube. It helps plan tracks, render videos, prepare thumbnails, write descriptions and translations, and upload the finished video. When the user connects their Google account, the app uses the YouTube Data API only to upload videos to the user's own channel and set their metadata. All project files stay on the user's computer.
